# wp custom community portal

This is a custom community portal plugin for Wordpress, still in development. In other words, it's like a reddit or facebook commenting system, with attachments. For this plugin to work, you need to install the [Members plugin](https://wordpress.org/plugins/members/), before you install this plugin.

## How to use

To display the posts, threads or whatever you want to call them. Use this shortcode:

`[wccp_portal]`

To add a top level post, thread or whatever, use this shortcode:

`[wccp_form]`
